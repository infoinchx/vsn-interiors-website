# Asset notes

The updated site uses 182 distinct AI-generated design visuals: 130 Gallery designs, 24 service photographs and 28 other page and 3D-fallback images. Every full visual has one assigned section. Thumbnails and enlarged views intentionally reuse the same design.

Eleven new images were generated on 8 October 2026 with OpenAI image generation, including a replacement for an empty inherited banner. They use contemporary Indian interiors and local material cues. They are design inspiration, not completed VSN project photography. Files are stored locally as WebP. The original generated PNG files were preserved outside this deliverable; the website uses optimized versions.

`IMAGE-PLACEMENTS.json` contains current assignments. `IMAGE-GENERATION-2026.json` contains the new concept prompts. Earlier generation records are retained for the existing collection.

The official logo and founder photograph come from the supplied project. Original branding files are in `brand-assets`; website versions are in `public/images/brand`. No generated portrait replaces the founder. The co-founder profile remains hidden until its actual details are configured.

All interface text uses Arial. Icons are provided by Lucide and the existing WhatsApp SVG. The procedural Three.js interior is generated by source code and does not use a downloaded model.

Existing Google review summaries and their dated source attribution are preserved. This update did not retrieve new reviews or change their checked date.
